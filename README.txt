# CSCI218-GroupProject-MT

Step 1: Make sure python 3.12 is installed (For those with dedicated NVIDIA GPUs especially)

Step 2: Create an enviroment for it by typing the following into the file terminal:
py -3.12 -m venv venv

Step 3: Run the following after the enviroment initialization:
.\venv\Scripts\activate

Step 4: Run the following after activation:
python install_requirements.py

Step 5: In the same terminal run the following to test each different python files:
python rnn.py
python mlp.py
